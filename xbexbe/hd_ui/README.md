# Restored UI enhancements

`overrides.toml` is the active allowlist of the 68 approved enhancement PNGs.
These reconstruct detail in the menu, font and HUD artwork while retaining the
game's composition. The runtime can select the HD UI separately from gameplay
resolution. Intro slides are separate replacements; movie files are unchanged.

These images are enhancements derived from Darkwatch artwork, not a freely
licensed asset library. The original artwork and marks retain their underlying
rights. No original disc archive, movie, audio, source screenshot or assembled
`hd-ui.pack` is distributed here. The builder combines these enhancements with
the player's verified original files locally.
