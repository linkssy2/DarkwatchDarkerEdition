# Dependency notices

These are license copies from the exact SDK and dependency checkouts used for
version 0.1. `dependencies.lock.json` records the corresponding revisions.
They do not license the original game or all project artwork under the same
terms. See the root `COPYRIGHT` and `launcher/assets/SOURCES.md` for that boundary.

The Windows package also includes notices for its embedded Python, OpenSSL,
libffi and Microsoft Visual C++ redistributables. Those generic binaries and
their packaging-time notices are supplied locally when rebuilding the package;
see `docs/BUILDING.md`.
