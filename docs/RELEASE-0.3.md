# Darkwatch: Darker Edition — 0.3

- Added **Weapon FOV**, adjustable independently of world FOV.
- Added **Cutscene Borders** for in-level cutscenes; FMVs are unchanged.
- Improved Graphics text fit and matched **Quit to Desktop** to the main menu's font size.

Use the **Windows x64 ZIP** to play. Extract it, run **Darkwatch Darker Edition.exe**,
and import your own supported original Xbox ISO or XISO. **Play Darkwatch.exe**
starts the installed game directly.

To update, copy your **GameData** folder into a fresh extraction, then use
**Import / Repair** with your disc image. Keep your old folder until you verify
your saves.

Routine diagnostics are disabled; bounded local error reports remain for failures.
No original disc assets or generated game source are bundled. Full-campaign
validation remains open.
