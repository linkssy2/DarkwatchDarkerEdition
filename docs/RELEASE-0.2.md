# Darkwatch: Darker Edition — 0.2

**[Download version 0.2 for Windows x64](https://github.com/linkssy2/DarkwatchDarkerEdition/releases/download/v0.2/Darkwatch-Darker-Edition-0.2-Windows-x64.zip)**

A full portable Windows release for community testing. This package carries
forward the gameplay changes from 0.1.1 Test 1; it does not claim new gameplay
validation. Choose the Windows ZIP to play, not the source archive.

- Enables **War Train** and retained **Splitter Grenade** campaign placements
  from your own supported Xbox disc. Paired Xbox dynamite replacements are
  disabled to avoid duplicate pickups; ordinary dynamite is unchanged.
- Corrects an actor-script timing gate that skipped updates above 100 FPS,
  linked to the first door staying closed at 144 FPS.
- Enables direct mouse aiming during vampire jumps through the existing
  guarded look path.
- Retains mouse-friendly menus and bindings, controller prompts, graphics
  settings, portable saves and local shader preparation. Existing HD artwork
  covers the War Train chapter preview and shared menus, fonts and Splitter HUD.

Extract the entire ZIP to a writable folder and run **Darkwatch Darker Edition.exe**.
Import your supported original Xbox ISO or XISO, wait for preparation, then play.
After setup, **Play Darkwatch.exe** starts the game directly. Normal play has no timer.

To update, extract into a new folder and copy your existing **GameData** folder
into it. Use **Import / Repair** with your original ISO or XISO; reimport is
required for older installations to enable the bonus content. Setup preserves
saves, settings and compatible shader cache. Keep the old installation until
you have checked your progress.

Original campaign progression is retained. After picking up Splitter Grenades,
use the D-pad Up action (**Up Arrow** by default) to change grenade type. No PS2
disc or downloaded game files are required.

Please report results for the first door at 144 FPS, vampire-jump mouse aiming,
War Train progression and grenade behavior. Import, integrity, HD preparation
and focused offline checks pass; these gameplay changes still need live
acceptance. Full-campaign completion, fresh Windows and physical PS4/Switch
testing remain unverified. Other high-FPS physics or event differences and
occasional shader/loading pauses may remain.

No original disc assets, generated game source, saves, shader caches or diagnostic
logs are bundled. The Windows player contains compiled recompiled gameplay;
approved HD enhancement artwork and edited launcher branding are included.
Routine diagnostics are disabled; failures retain a short local error report.
